# Project: QR Platform

## Core Purpose
A full-stack Next.js web application dedicated to generating dynamic QR codes, managing related reviews, scanning logs, and administering the operational data.

## Target Audience
Administrators managing QR codes for businesses, and end-users scanning those tracking codes to leave reviews or interact with services.

## Key Subsystems
1. **QR Generation Core**: Handles the creation and customization of dynamic QR Codes.
2. **Review/Rating Engine**: Smart review system tracking and recording scan logs.
3. **Admin Dashboard**: Gated management interface for user/session stats and modifying records.
4. **Ops Diagnostics**: A hefty set of `.exp` (expect) scripts handling VPS sanity, networking setups, Nginx routing, and SQLite checking.
