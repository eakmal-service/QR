# Tech Stack

- **Framework**: Next.js 14.2.25 (App Router)
- **Language**: TypeScript (`typescript: ^5`)
- **Frontend library**: React 18
- **Styling**: Tailwind CSS v4.1.9 with PostCSS
- **Database ORM**: Prisma 6.19.0
- **Database Provider**: SQLite (based on `dev.db` seen in root)
- **Authentication**: NextAuth 4.24.13 with `@next-auth/prisma-adapter`
- **Animation Libraries**: Framer Motion, GSAP, `@react-three/fiber`
- **UI Components**: Radix UI primitives (`@radix-ui/react-*`), Lucide React icons
- **Form Handling**: `react-hook-form` + `zod` + `@hookform/resolvers`
- **QR Generation**: `qrcode.react`, `qr-code-styling`
